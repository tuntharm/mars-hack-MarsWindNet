# Solver output landing directory

No genuine solver result has been supplied yet. Put your exported result and optional exact-point observations here; see [CFD/README.md](../README.md). Raw files in this directory are ignored by Git to avoid accidentally publishing large solver work products.

`npm run cfd:import -- CFD/results/result.json [CFD/results/observations.json]` validates and publishes compact display data into `public/data/scenarios/`. Review and commit those imported files if the team intends to share them. Existing analytic examples live separately in that directory and are labelled illustrative.
